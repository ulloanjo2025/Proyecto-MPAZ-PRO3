# Microservicios de MPAZ PRO 3.º

- `ms-contenido` (puerto 8081): Objetivos de Aprendizaje y preguntas.
- `ms-seguimiento` (puerto 8082): estudiantes (CRUD) e intentos.

Cada carpeta es un proyecto Spring Boot independiente (Java 17, Gradle, H2 en archivo).
Para encenderlos: `./gradlew bootRun` dentro de cada carpeta (en Windows `gradlew.bat bootRun`).
